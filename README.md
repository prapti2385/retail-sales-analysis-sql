# Retail Sales Analysis using SQL

## Overview

This project analyzes retail sales data using SQL to extract meaningful business insights related to customer behavior, sales performance, and product trends.

## Problem Statement

The objective of this project is to analyze retail sales transactions and answer key business questions that can help stakeholders make data-driven decisions.

## Dataset

- Retail Sales Dataset
- Records: 1000
- Database: MySQL

## Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

## SQL Concepts Used

- SELECT
- WHERE
- DISTINCT
- GROUP BY
- ORDER BY
- LIMIT
- Aggregate Functions (COUNT, SUM, AVG, MAX, MIN)
- CASE Statements
- Subqueries

## Business Questions Answered

- How many records are present in the dataset?
- Are there any missing values?
- Which product category generated the highest revenue?
- Which category sold the highest quantity?
- How much revenue was generated by each gender?
- Which age group contributes the highest revenue?
- What is the average transaction value?
- Which are the top 10 highest-value transactions?
- Which month generated the highest revenue?
- What are the daily sales trends?
- Which customers made the highest number of purchases?
- Which transactions are above the average transaction amount?

## Key Insights

- Revenue varies significantly across product categories.
- Customer spending differs across age groups.
- Revenue contribution varies by gender.
- Seasonal sales trends can be identified through monthly analysis.
- High-value customers and transactions can be identified using SQL queries.
